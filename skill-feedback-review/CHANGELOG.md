# Changelog

## 0.1.0 (2026-10-07)

- Initial release.
- Reads recent chats (Claude Code session history, or claude.ai past chats) for feedback on skills.
- Records direct comments, corrections, usage patterns and praise.
- Gives each signal a recommendation: update going forward, once-off, or unclear. The user decides.
- Drafts edits for "update going forward" items and flags the rest for review.
- Claude Code can edit and commit on a branch. Claude.ai outputs the updated file and git commands.
